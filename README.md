# REBOX Translator

Free Xbox Remote Play subtitle translator for iPhone/iPad and an experimental LG webOS receiver.

Source is being imported from the separately prepared project bundle. No phone camera, manual copy/paste, subscriptions, or paid translation API is required for the intended Xbox flow.

The automatic Xbox OCR, translation, LG browser HDMI composition and iOS IPA must be tested on real devices; a successful GitHub build does not verify HDMI overlay support.
